## 个人项目

**AutoFlow 汽车销售订单履约平台｜独立设计与实现**

技术栈：Java 17、Spring Boot、Spring Cloud、Nacos、MyBatis-Plus、MySQL、Redis、Redisson、RocketMQ、Vue 3、Docker Compose

- 基于汽车销售业务经验重构多渠道订单履约平台，将订单、库存、支付/交付划分为独立服务，实现从订单审核、车型配额预占、支付模拟、VIN 分配到交付完成的业务闭环；
- 针对门店热门车型并发预订，使用 Redisson 按门店和车型削峰竞争，并通过 MySQL `available > 0` 条件更新、版本号及订单/VIN 唯一约束兜底，保证 Redis 锁失效时仍不超卖；
- 采用 Transactional Outbox 与 RocketMQ 实现跨服务最终一致性，通过 `eventId` 幂等表、业务修改同事务、指数退避和死信补偿设计，避免重复扣库存、重复退款和消息丢失；
- 使用 Redis cache-aside 缓存门店范围内的订单详情，结合随机 TTL 与状态变更主动失效降低重复读取压力，并保持 MySQL 为库存事实源；
- 设计可扩展订单记录模型，使用来源页面、记录类型和 JSON 字段承载客户、收付款、退款、保险等子页面数据，统一门店隔离与操作审计；
- 使用 Docker Compose 编排 MySQL、Redis、Nacos、RocketMQ、Prometheus 和 Grafana，配置 outbox/死信业务指标、仪表盘与告警，并以集成、冒烟及并发测试验证一致性和库存不超卖。
